# Portfolio

A personal portfolio site built with React, Vite, and Tailwind CSS.

## Pages

- **Home** — intro and overview
- **Projects** — showcase of work
- **Expertise** — skills and experience
- **Contact** — get in touch

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
